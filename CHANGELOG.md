# Changelog

## 1.1.0

- Added live theme switching with `Mono`, `Purple`, `Blue`, `Light`, `Ocean`,
  `Crimson`, `AMOLED`, `System`, and custom themes.
- Added responsive sizing, compact-screen drawer navigation, shadows, glow
  borders, focus rings, hover states, and pressed states.
- Added notification severity colors through `Type = "info"`, `"success"`,
  `"warning"`, and `"error"`.
- Added optional session persistence with `Persist = true`, `PersistenceKey`,
  and optional `Persistence.Load`/`Persistence.Save` callbacks.
- Added `ReducedMotion`, `ReduceAnimations`, and `AnimationSpeed` options.
- Added `examples/theme_showcase.luau`.

## 1.0.0

- Initial reusable Draco UI library and loadstring distribution.
